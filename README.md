# Bitcoin Simulation and Moving Average Strategy

This project simulates 60 days of Bitcoin prices using a Geometric Brownian Motion model to inject realistic volatility. It computes the 7-day and 30-day Moving Averages (MA) using pandas, and simulates a Golden Cross trading strategy (buying when 7-MA crosses above 30-MA, selling when it crosses below).

Run `python3 btc_simulator.py` to view the simulation daily ledger and final portfolio performance.
